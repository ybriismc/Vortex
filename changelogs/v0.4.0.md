# v0.4.0

Vortex now speaks Minecraft: Bedrock Edition **1.26.45, protocol 2169**.

## Protocol

- gophertunnel updated from v1.57.1 to **v1.61.0**, which moves the proxy from
  protocol 1001 (1.26.30) to **2169 (1.26.45)**.
- The protocol is reported where it matters: `./vortex -version` prints it, and
  it appears in the startup and ready log lines.

Downstream servers have to run on the same protocol. A client on an older
version is refused by the listener during login.

## Patched Spectrum

Spectrum has no release built against gophertunnel v1.61.0: the library moved
`ActionType` out of the `PlayerList` packet and into each entry, which does not
compile with Spectrum v0.0.44.

To ship the protocol update anyway, `third_party/spectrum` holds Spectrum v0.0.44
with that single change applied, used through a `replace` in `go.mod`. The two
patched places are marked in `session/tracker.go` and documented in
`third_party/spectrum/PATCH.md`, which also gives the steps to drop the fork once
upstream catches up. Nothing else in Spectrum was touched.

## Notes

- The plugin API is unchanged, but plugins link against gophertunnel too, so
  **rebuild your plugins** after updating the proxy.
