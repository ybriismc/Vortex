# v0.2.0

Vortex gains a plugin API: a plugin subscribes to proxy events and acts on the
proxy through a small interface.

## Plugin API

- **`plugin` package.** `Plugin` interface with `Manifest`, `Load`, `Enable` and
  `Disable`, registration from an `init` function, dependency ordering, per
  plugin directory, logger and `config.yml`, and a `Base` type for the no-op
  lifecycle methods.
- **`event` package.** Generic bus with `Subscribe`, `Call` and `Subscribed`,
  six priorities from `Lowest` to `Monitor`, cancellable events and panic
  recovery: a handler that panics is logged with the plugin's name and the
  remaining handlers still run.
- **Events.** `ProxyStart`, `ProxyStop`, `PlayerLogin`, `PlayerJoin`,
  `PlayerQuit`, `ServerSelect`, `Transfer`, `TransferComplete`,
  `TransferFailed`, `Chat` and `Command`.
- **Proxy functions.** `Sessions`, `Session`, `SessionByXUID`, `Count`,
  `Transfer`, `Kick`, `Message`, `Broadcast`, `Servers`, `SetServers`,
  `Fallbacks`, `SetFallbacks`, `Plugins` and `Logger`.

Plugins are compiled into the binary: they register from an `init` function and
the package is imported in `cmd/vortex`. Go cannot load code at runtime in a way
that survives a version bump, so this trades hot loading for real Go types,
direct calls and no serialization on the event path.

## Notes

- `PlayerLogin` fires before the session exists and before any server is
  contacted, which makes it the cheap place for bans and whitelists.
- `Chat` and `Command` are the only events that cost throughput: the proxy
  decodes text and command packets only while something is subscribed to them.
- The Bedrock client only sends commands present in its command tree, so a
  proxy side command has to be registered by a server, or triggered from chat.

## Added

- `plugins` section in `config.yml`: `enabled`, `directory` and `disabled`.
- `examples/plugins/greeter`, a working plugin covering joins, quits and a
  proxy side `/players` command.
- Plugin API documentation at https://ybriismc.github.io/Vortex/plugins.html
