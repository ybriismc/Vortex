# v1.0.0

First stable release of Vortex, a Minecraft: Bedrock Edition proxy built on
[Spectrum](https://github.com/cooldogedev/spectrum).

Speaks Minecraft **1.26.45, protocol 2169**.

## Downloads

| File | For |
| --- | --- |
| `vortex-linux-amd64.tar.gz` | The proxy on Linux x86-64, loads plugins |
| `vortex-linux-arm64.tar.gz` | The proxy on Linux ARM64, loads plugins |
| `vortex-windows-amd64.zip` | The proxy on Windows, without plugin loading |
| `vortex-darwin-amd64.tar.gz` / `vortex-darwin-arm64.tar.gz` | The proxy on macOS |
| `checksums.txt` | SHA-256 of the proxy archives |

Run `./vortex` once to get a `config.yml`, point `servers.primary` at your
lobbies and start it again.

## The proxy

- **Spectrum based**, with the Spectral and QUIC transports to the downstream
  servers, a stateless design and no RakNet between proxy and server.
- **Balanced discovery** over pools of primary and fallback servers, with
  `round_robin`, `random` and `first`.
- **Packet guard**: per session rate limit, block list by packet identifier and
  a maximum packet size, all without decoding packets that do not need it.
- **Transfer animations**: `dimension`, `fade`, `smooth` and `ease`, with the
  camera following the player.
- **API service** over TCP, with secret based authentication, so servers and
  tooling can transfer and kick players.
- **Resource packs** served by the proxy, with content key support.
- **Operations**: YAML configuration validated on boot, text or JSON logs, a
  clean shutdown, a Pterodactyl egg and `start.sh` for private hosts.

## Plugins

- A plugin API with an event bus: priorities, cancellable events and panic
  recovery around every handler.
- Events for the proxy lifecycle, logins, joins, quits, server selection,
  transfers, fallbacks, chat and commands. `PlayerLogin` runs before a session
  exists, which is where bans and whitelists belong.
- Plugins are loaded from the `plugins/` directory at startup, built with
  `go build -buildmode=plugin`, and can also be compiled into the binary.
- Full reference: https://ybriismc.github.io/Vortex/plugins.html

## Downstream servers

The servers behind the proxy must speak the Spectrum protocol:
[spectrum-pm](https://github.com/cooldogedev/spectrum-pm) for PocketMine-MP or
[spectrum-df](https://github.com/cooldogedev/spectrum-df) for Dragonfly. A
Bedrock Dedicated Server cannot be one of them: its network stack belongs to
Mojang and speaks RakNet, not Spectrum.

## Notes

- Loading plugins requires the proxy to be built with cgo: the Linux builds are,
  the Windows and macOS builds are not.
- Plugins must be rebuilt against every release of the proxy.
- `third_party/spectrum` carries Spectrum v0.0.44 with a two line patch for
  gophertunnel v1.61.0. See `third_party/spectrum/PATCH.md`.
