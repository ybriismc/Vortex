# v0.1.0

First release of Vortex, a Minecraft: Bedrock Edition proxy built on top of
[Spectrum](https://github.com/cooldogedev/spectrum).

## Highlights

- **Configuration file.** Everything is driven by `config.yml`, generated with
  the default values on the first run and validated before the listener starts.
- **Balancing.** Players are spread over the `servers.primary` pool and sent to
  `servers.fallback` when the server they are on dies mid-game.
- **Guard.** A Spectrum `Processor` that rate limits each session, blocks client
  packets by identifier and rejects oversized packets. Blocking reads the
  identifier from the packet header, so packets are never decoded just to be
  filtered.
- **Controlled login.** The guard and the animation are attached to the session
  before the login sequence starts, so no packet reaches the server unfiltered.
- **Transports.** `spectral` (default, no encryption, lowest overhead) and
  `quic` (TLS 1.3) to the downstream servers.
- **API.** Spectrum's TCP service, with secret based authentication, lets the
  servers transfer and kick players.

## Deployment

- `start.sh` for private hosts: installs the toolchain when missing, builds the
  binary and starts the proxy.
- A Pterodactyl egg in `pterodactyl/` that downloads the release build.
- Release builds for Linux, Windows and macOS on amd64 and arm64.

## Notes

- The downstream servers must run
  [spectrum-df](https://github.com/cooldogedev/spectrum-df) or
  [spectrum-pm](https://github.com/cooldogedev/spectrum-pm), and their transport
  must match `proxy.transport`.
- On Linux, raise the kernel network buffers before going to production
  (`./start.sh --tune`).
